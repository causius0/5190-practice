A real, seeded run of my own small network (SGD, lr 0.35, batch 32, task: is x₁·x₂ positive), not a figure from any paper. The 64 evaluation points never change, so any change in a layer's distribution comes from weight updates.

  • The step axis is training time. One forward pass has no drift because the weights are fixed while it runs. Drift appears across passes: every update changes earlier layers, so the next batch reaches layer k with a different distribution.
  • IS15 · §1, §2Internal covariate shift: the distribution of a layer's inputs changes during training because earlier layers' parameters change. BN is introduced to reduce it.
  • ST18 · §2.1, Fig 1Injecting noise after BN (non-zero mean, non-unit variance, changing over time) barely hurts training, so stable input distributions are not what makes BN work.
  • ST18 · §2.2, Def 2.1A gradient-based version of ICS (how much a layer's gradient changes after earlier layers update) is often not reduced by BN.

IS15 · §3, Alg. 1Batch normalizing transform (Ioffe & Szegedy 2015)

\[\begin{aligned} \mu_B &= \frac{1}{m}\sum_{i=1}^{m} x_i &&\text{mean of the batch} \\ \sigma_B^2 &= \frac{1}{m}\sum_{i=1}^{m} (x_i-\mu_B)^2 &&\text{variance (spread) of the batch} \\ \hat{x}_i &= \frac{x_i-\mu_B}{\sqrt{\sigma_B^2+\epsilon}} &&\text{normalize; } \epsilon\text{ keeps the denominator away from 0} \\ y_i &= \gamma\,\hat{x}_i+\beta &&\text{scale and shift with learned } \gamma,\beta \\[10pt] \gamma &= \sqrt{\mathrm{Var}[x]} &&\text{with these two values } y_i=x_i\text{: BN is undone} \\ \beta &= \mathrm{E}[x] \end{aligned}\]
μ_B  = (1/m) Σ x_i                 mean of the batch
σ²_B = (1/m) Σ (x_i − μ_B)²        variance (spread) of the batch
x̂_i  = (x_i − μ_B) / √(σ²_B + ε)   normalize; ε keeps the denominator away from 0
y_i  = γ · x̂_i + β                 scale and shift with learned γ, β

γ = √Var[x]   with these two values y_i = x_i: BN is undone
β = E[x]

The Jacobian: who affects whom

One neuron, the same batch as the box above. Drag a point there and this grid updates.

One neuron, a batch of m observations. Every observation has an input x (what this neuron feeds into BN) and an output y (what BN returns). Each cell pairs two observations from the same batch: column j is the one whose input you change, row i is the one whose output you watch. Cell (i, j) = ∂yi/∂xj: how much observation i's output moves when observation j's input moves. When i = j it is the same observation. Diagonal cells (dashed outline) are an observation's effect on its own output; off-diagonal cells are one observation's effect on another observation's output.

Without BN

Each observation passes through on its own (yi = xi), so the diagonal is 1 and every off-diagonal cell is 0: observations never affect each other.

With BN

Every observation's output uses the batch mean and variance, so every cell is non-zero. The diagonal is a bit below γ/s. Off-diagonal cells, −(γ/s)(1 + x̂ix̂j)/m, are small and usually negative: raising one observation's input lifts the mean and pulls the other outputs down. A cell turns positive when the two observations sit far apart on opposite sides of the mean (x̂ix̂j < −1).

A layer with many neurons has one matrix like this per neuron. BN never mixes neurons, only observations.

Click a cell to see where its value comes from.

Backward pass: ∂ℓ/∂xⱼ = Σᵢ ∂ℓ/∂yᵢ · Jᵢⱼ. Read down column j: the gradient reaching input j collects a share from every output. The off-diagonal cells are the cross-sample gradients. Without BN they are all zero.

With BN every row and every column sums to 0. Rows: shifting all inputs by the same amount changes no output, because BN subtracts the mean. Columns: moving one input never changes the total of the outputs, which stays m·β. The row sums are also why the input gradients always add up to 0.

IS15 · §2Backprop through normalization needs the Jacobian with respect to the whole batch, not just the observation itself. The cell formula Jᵢⱼ = (γ/s)(δᵢⱼ − 1/m − x̂ᵢx̂ⱼ/m) is my own algebra from IS15's chain rule, and the table checks it against a finite-difference derivative.

\[\begin{aligned} \frac{\partial \ell}{\partial \hat{x}_i} &= \frac{\partial \ell}{\partial y_i}\,\gamma \\[6pt] \frac{\partial \ell}{\partial \sigma_B^2} &= \sum_{i=1}^{m}\frac{\partial \ell}{\partial \hat{x}_i}\,(x_i-\mu_B)\cdot\left(-\tfrac{1}{2}\right)(\sigma_B^2+\epsilon)^{-3/2} \\[6pt] \frac{\partial \ell}{\partial \mu_B} &= \left(\sum_{i=1}^{m}\frac{\partial \ell}{\partial \hat{x}_i}\cdot\frac{-1}{\sqrt{\sigma_B^2+\epsilon}}\right)+\frac{\partial \ell}{\partial \sigma_B^2}\cdot\frac{\sum_{i=1}^{m}-2(x_i-\mu_B)}{m} \\[6pt] \frac{\partial \ell}{\partial x_i} &= \frac{\partial \ell}{\partial \hat{x}_i}\cdot\frac{1}{\sqrt{\sigma_B^2+\epsilon}}+\frac{\partial \ell}{\partial \sigma_B^2}\cdot\frac{2(x_i-\mu_B)}{m}+\frac{\partial \ell}{\partial \mu_B}\cdot\frac{1}{m} \\[6pt] \frac{\partial \ell}{\partial \gamma} &= \sum_{i=1}^{m}\frac{\partial \ell}{\partial y_i}\,\hat{x}_i \\[6pt] \frac{\partial \ell}{\partial \beta} &= \sum_{i=1}^{m}\frac{\partial \ell}{\partial y_i} \end{aligned}\]
∂ℓ/∂x̂_i = ∂ℓ/∂y_i · γ
∂ℓ/∂σ²  = Σ_i ∂ℓ/∂x̂_i · (x_i − μ) · (−½)(σ²+ε)^(−3/2)
∂ℓ/∂μ   = (Σ_i ∂ℓ/∂x̂_i · (−1/√(σ²+ε))) + ∂ℓ/∂σ² · Σ_i(−2(x_i−μ))/m
∂ℓ/∂x_i = ∂ℓ/∂x̂_i / √(σ²+ε) + ∂ℓ/∂σ² · 2(x_i−μ)/m + ∂ℓ/∂μ · 1/m
∂ℓ/∂γ   = Σ_i ∂ℓ/∂y_i · x̂_i
∂ℓ/∂β   = Σ_i ∂ℓ/∂y_i

IS15 · §3The block above is the paper's chain rule. Terms 2 and 3 of ∂ℓ/∂x_i are the cross-sample part: σ² and μ are sums over the batch.

\[\begin{aligned} g_i &= \gamma\,\frac{\partial \ell}{\partial y_i}, \qquad s=\sqrt{\sigma_B^2+\epsilon} \\[6pt] \frac{\partial \ell}{\partial x_i} &= \frac{1}{m\,s}\Big(m\,g_i-\sum_{j=1}^{m} g_j-\hat{x}_i\sum_{j=1}^{m} g_j\,\hat{x}_j\Big) \end{aligned}\]
g_i = γ · ∂ℓ/∂y_i,     s = √(σ²+ε)
∂ℓ/∂x_i = (1 / (m·s)) · ( m·g_i − Σ_j g_j − x̂_i · Σ_j g_j x̂_j )

Compact form is my algebra, not printed in IS15 or ST18. I checked it against the paper's three-term form (agreement ~1e-15) and against finite differences (~2e-9) on a seeded batch of 6.

  • IS15 · §3 after Alg. 1Explicit backward formulas for ∂ℓ/∂x̂, ∂ℓ/∂σ², ∂ℓ/∂μ, ∂ℓ/∂x_i, ∂ℓ/∂γ, ∂ℓ/∂β (block above).
  • IS15 · §2Backprop through normalization needs the Jacobian with respect to the observation and with respect to the whole set. Ignoring the second leads to blow-up (their bias-update observation).
  • ST18 · §4.2, Thm 4.1Indirect: bounds the gradient norm with a γ²/σ_j² factor and subtracts the components of the gradient along the all-ones direction and along ŷ. Same structure as the projection read below.
  • ST18 · §4.2, Thm 4.2Analogous bound for the Hessian quadratic form.
  • Σ_i ∂ℓ/∂x_i = 0 exactly: BN's backward pass removes the all-ones direction from the incoming gradient.
  • Σ_i x̂_i ∂ℓ/∂x_i = 0 only in the limit ε → 0 (residual scales like ε/(σ²+ε)).
  • Reading: BN's backward acts like projecting the upstream gradient away from "all ones" and "along x̂" within the batch, consistent in spirit with ST18 Thm 4.1.
  • With BN every off-diagonal cell of the Jacobian is non-zero; without BN they are all zero. Those off-diagonal cells are the cross-sample gradients.
